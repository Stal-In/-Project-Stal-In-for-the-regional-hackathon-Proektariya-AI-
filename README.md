# Stal-In

Веб-приложение на FastAPI для классификации дефектов стальных листов по 27 числовым признакам. Чтобы пройти демонстрацию без своего файла, выберите **Открыть пример**, затем **Открыть проверку партии**. Пример содержит 128 записей из датасета UCI Steel Plates Faults с исходными значениями всех 27 признаков. 

## Запуск в Windows

В PowerShell из папки проекта выполните пошагово:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Для повторного запуска достаточно последней команды. Откройте [Stal-In](http://127.0.0.1:8000). Проверено с Python 3.13. При запуске программа загружает три сохранённые модели XGBoost из папки `base model`.

## Файлы для распознавания

Имена 27 обязательных полей перечислены в первых 27 строках `Faults27x7_var`. Порядок полей произвольный. CSV использует UTF-8, запятую между столбцами и точку в дробных числах. JSON принимает объект или массив объектов. BSON принимает один документ или документ с массивом `records`. В JSON и BSON передавайте числа. Дополнительные столбцы игнорируются. При ошибке интерфейс показывает номер записи и поле. Запись 0 обозначает ошибку структуры файла или заголовка.

## Работа контролёра

- **Распознавание и дашборд** показывает прогнозы и аналитику загруженной партии на одной странице. Таблица прогнозов доступна для скачивания в CSV.
- **Проверка** поднимает партии со сдвигом в начало списка. Для мониторинга нужно 30 записей. Очередь учитывает неопределённость модели и разнообразие примеров. Контролёр подтверждает или исправляет предложенный тип, затем вручную запускает дообучение.
- **Качество** показывает accuracy, macro-F1 и показатели каждой категории. Accuracy — доля верных ответов, macro-F1 усредняет F1 семи классов с одинаковым весом. Рейтинги UCI и текущей партии подписаны по источнику меток.

В меню **Модель** доступны Baseline v0, GridSearch v1, Optuna v1.1 и все версии случайного леса, сохранённые после дообучения. Для этих версий дашборд показывает прямые прогнозы на всём UCI. Для прогноза через API с моделью Optuna используйте `POST /api/predict?version=1.1`. На телефоне меню находится в шапке, на широком экране в боковой панели. Новая сессия начинается с v1. Дообучение сохраняет новую версию в `.stal-in/work.db`, где также хранятся партии и подтверждённые метки. Текущий выбор меняется вручную через список моделей. Файлы в `base model` открываются только для чтения. Для независимого рабочего пространства можно задать путь переменной `STAL_IN_WORKSPACE`. Приложение открывает файлы SQLite предыдущей версии проекта.

Базовая модель использует XGBoost. При дообучении приложение тренирует случайный лес из 160 деревьев. Стратифицированное разбиение с семенем 42 выделяет около 50% данных для обучения, 15% для настройки порогов мониторинга, 15% для разметки и 20% для теста. Контрольные наблюдения исключаются из дообучения.

Графики построены с помощью Matplotlib и Seaborn. Прототип оценивает качество на UCI. Для оценки производственных затрат нужны данные предприятия и фактические ставки.

На экране качества можно выбрать загруженную партию или весь UCI из 1 941 записи. Для партии приложение сравнивает прогнозы выбранной версии модели с подтверждёнными метками контролёра и показывает число проверенных записей. Основные показатели рассчитаны по вневыборочным прогнозам на пяти стратифицированных разбиениях. В сравнении отдельно показана фактическая accuracy сохранённых моделей на всех 1 941 записях, включая примеры из обучения. Раздел сравнения также показывает результаты повторного обучения трёх конфигураций по схеме 5×2 CV. Для пересчёта выполните `python analysis/validate_tuned.py`.

## HTTP API

[Интерактивная документация OpenAPI](http://127.0.0.1:8000/docs) доступна после запуска.

| Метод и адрес | Назначение |
| --- | --- |
| `GET /healthz` | Проверка готовности приложения |
| `GET /api/models` | Список доступных версий |
| `POST /api/predict?version=1` | Прогнозы для файла CSV, JSON или BSON в поле `file` формы multipart. Вызов не сохраняет партию в рабочем пространстве. |

## Размещение на Render

Для будущего Web Service с Python укажите команды и путь проверки готовности.

| Параметр | Значение |
| --- | --- |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn app:app --host 0.0.0.0 --port $PORT` |
| Health Check Path | `/healthz` |
| `STAL_IN_SESSION_SECRET` | Случайный секрет, заданный в настройках сервиса |

Для сохранения партий, разметки и версий между перезапусками подключите постоянный диск к `/var/data` и задайте `STAL_IN_WORKSPACE=/var/data/work.db`. На Render постоянные диски доступны для платных сервисов. Приложение использует общее рабочее пространство для пользователей одного экземпляра. [Запуск FastAPI на Render](https://render.com/docs/deploy-fastapi) · [Постоянные диски](https://render.com/docs/disks)
